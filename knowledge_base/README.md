# Base de Conocimiento de Trading — TradIA

Este directorio está diseñado para almacenar **transcripciones de cursos, libros y vídeos de trading** que servirán como marco de referencia contextual para el usuario.

## 🛡️ Principio Fundamental de Seguridad y Robustez
- **Cero reentrenamiento automático y ciego**: El bot **NUNCA** modificará su código ni sus umbrales automáticamente a partir de textos.
- **Supervisión Humana Exclusiva**: El conocimiento depositado aquí sirve como guía documentada para que el **USUARIO** compare el rendimiento del bot (mediante los informes periódicos) y decida manualmente si ajustar parámetros en `config/config.yaml`.

## Estructura de Directorios
- `transcripts/`: Coloca aquí archivos de texto (`.txt`, `.md`) con notas, transcripciones o resúmenes de formaciones.
- `trading_rules_guide.md`: Resumen consolidado de reglas maestras de entrada, gestión de riesgo y filtros de tendencia acordados.
